# Mission index: every honest way to get a position, and what to load

Generated by `tools/mission_index.py` from `upin/layers/mission_catalog.py`. Regenerate after any change there. Every accuracy figure is a **simulation** figure until the bench says otherwise.

Ask it directly:

```bash
python tools/mission_index.py --have flight_controller,gnss_receiver,camera,rangefinder --situation jammed
```

## Situations

| Key | Meaning |
|---|---|
| `gnss_healthy` | GNSS healthy |
| `jammed` | GNSS jammed (no fix) |
| `spoofed` | GNSS spoofed (a fix, but a lie) |
| `long_denial` | GNSS denied for minutes |
| `night` | night or no light |
| `featureless` | featureless ground or water |
| `indoor` | indoor |
| `fast` | moving fast |
| `still` | stationary or hovering |

## Hardware tags

| Tag | Meaning |
|---|---|
| `flight_controller` | ArduPilot flight controller over MAVLink (IMU, compass, barometer) |
| `gnss_receiver` | a GNSS receiver on the box with UBX output (NAV-PVT, NAV-SAT, MON-RF) |
| `raw_gnss` | a receiver with raw pseudoranges (and the ephemeris decoder, not built) |
| `second_receiver` | a second GNSS receiver or the flight controller's own |
| `camera` | a downward camera on the box |
| `rangefinder` | a downward rangefinder on the flight controller |
| `flow_chip` | an optical-flow sensor on the flight controller |
| `tags_surveyed` | printed UPIN tags at surveyed spots |
| `beacon_radio` | a ranging radio on the box, with a shared secret |
| `beacons_deployed` | three or more known-position beacons on the beacon band |
| `crumb_dispenser` | breadcrumb units and a release mechanism |
| `formation_peers` | two or more drones flying together, each with the box and a ranging radio |
| `pitot` | a real airspeed sensor (fixed wing) |
| `sdr` | an RTL-SDR dongle and a VHF antenna, with fresh orbit elements |
| `trained_model` | an AI motion predictor model trained on this airframe's flights |
| `georeferenced_map` | an Indian-source map with charted landmarks |
| `attitude_mode_fc` | a flight controller in a non-GPS attitude mode (GUIDED_NOGPS) |
| `command_log` | a readable motor-command stream from the flight controller |

## Fallback ladders

When a rung is missing or declines, the next one carries on, at the cost shown.

### Velocity

1. **Flight controller's flow sensor, integrity-checked** — sub-metre per second; needs light and texture
2. **Camera optical flow with weighted RANSAC (148)** — about 0.2-0.4 m/s; throws out moving patterns
3. **AI motion predictor (147)** — about 0.5 m/s, worse outside its training; no camera needed
4. **Wind-and-tilt dead reckoning (lean + frozen wind, or pitot)** — about 1 m/s, growing as the frozen wind goes stale; no extra sensor
5. **HonestKalman fusion** — coasting: the circle grows with the square of time

### Position

1. **The receiver's own fix, checked (box gateway)** — metres, while trusted
2. **Tag landmarks (149)** — sub-metre while a tag is in view
3. **Known-position beacons, balloons included (151)** — metres to tens of metres while beacons are up
4. **Breadcrumb beacons (152)** — tens of metres along the trail
5. **Formation cross-check and cooperative fix (153)** — about ten metres while two peers keep trusted GNSS
6. **LEO Doppler anchor (150)** — hundreds of metres, once per pass, when still
7. **HonestKalman fusion** — dead reckoning from the last fix: the circle grows
