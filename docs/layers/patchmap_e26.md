### Conditions that must hold

Even with every sensor attached, this layer declines unless:

- daylight and textured ground
- a map patch within the prior's radius
- a correlation peak above MIN_PEAK with no rival

### Notes

Never stores a patch from an untrusted or loose fix. Every fix carries the stamp sigma of the patches it matched.

## How to run it

This layer takes real input through its own methods and never invents a reading:

- `feed_frame()`
- `feed_attitude()`
- `feed_height()`
- `set_prior()`

Call those methods from a driver or the application. With nothing supplied it declines and names what is missing.

## When to use it

From the mission index ([`docs/MISSION_INDEX.md`](../MISSION_INDEX.md)); every figure is a simulation figure.

| Situation | Works? | Why |
|---|---|---|
| GNSS healthy | limited | builds the map; no fix needed then |
| GNSS jammed (no fix) | yes | an absolute fix over surveyed ground; nothing to jam |
| GNSS spoofed (a fix, but a lie) | yes | the ground cannot be spoofed; re-anchors the estimate |
| GNSS denied for minutes | yes | every pass over surveyed ground resets the drift |
| night or no light | no | needs light |
| featureless ground or water | no | no texture: declines |
| indoor | limited | a textured floor surveyed before |
| moving fast | limited | motion blur; the search radius grows with the prior |
| stationary or hovering | yes |  |
