### Live inputs

| Input | Units | Supplied via | Why |
|---|---|---|---|
| motor commands | throttle 0-1, attitude in radians | `log_command()` | throttle and attitude integrate into displacement |
| trusted starting position | degrees, metres | `set_anchor()` | dead reckoning measures change, so it needs a point to measure change from |

### Conditions that must hold

Even with every sensor attached, this layer declines unless:

- an airframe model fitted by least squares to real flight logs
- calibration flights reaching about 5 m/s, or the drag coefficient is not identifiable
- a recent anchor: accuracy degrades with every second since one

### Notes

Needs no sensor beyond the flight controller's own log, so it survives total sensor and signal loss. It is a bridge between fixes, not a solution -- it drifts and must be reset.
